
This project contains a simulation study about measurement error,
conducted by Boulesteix et al. (2020) in their study on the
‘Introduction to statistical simulations in health research’. The main
project folder contains a renv.lock file to ensure reproducibility. The
packages used include: renv, Hmisc, mice, and tidyverse. The package
environment can be restored using the renv::restore() function from the
renv package. All analysis can be run by rendering the main analysis
script (“Exercise 2.qmd”).

The project contains the following folders:

- analysis: containing the main analysis script (“Exercise 2.qmd”) and
  rendered pdf of this script

- data: containing a folder with raw data used (description and links
  can be found in the main analysis script) and the clean data after
  preprocessing

- figures: containing all figures generated by the main analysis script

- scripts: containing functions used in the main analysis script
